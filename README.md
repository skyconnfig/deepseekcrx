# Deepseek Assistant Chrome 插件

一个强大的 Chrome 浏览器插件，支持快速调用 Deepseek API 进行问答，并将对话记录保存到数据库中。

## 功能特点

- 右键选中文本快速提问
- 支持 Deepseek 官方 API 和本地模型
- 历史记录查询和管理
- 可配置的 API 设置
- 数据本地持久化存储

## 系统要求

- Windows 7 或更高版本
- Chrome 88 或更高版本
- Node.js v14.0.0 或更高版本
- SQL Server 2019 或更高版本
